# Agent 记忆架构（Read / Write / Reflection）

## 定义

Agent Memory Architecture 是让 LLM Agent **根据过往经验调整行为、而不更新模型参数**的三模块记忆架构：**Read（读取）**、**Write（写入）**、**Reflection（反思）**。它是 [[Memory_Agent]] 的一种具体落地范式——把"自己个人的经历"当作可检索的长期记忆库，让模型只在相关经验的辅助下继续文字接龙。

## 解决的问题

| 方案 | 问题 |
|------|------|
| 把全部历史经验塞进 Context | **超忆症**类比：第 100 步可行，第 1 万步时"一生的信息"太长，算力不足、无法抽象思考，反而做不出正确决策 |
| 每次都检索"全部"经验 | 与上面相同——需要筛选，只取与当前决策相关的经验 |
| 更新模型参数 | 本框架的**前提是不训练模型**（区别于 RL 调整参数），纯靠输入控制行为 |

## 三模块架构

```
                    ┌──────────────────────────────────────────┐
                    │            Long-term Memory              │
                    │   （个人经历数据库 / 工具包 / 知识图谱）      │
                    └──────┬─────────────┬────────────┬─────────┘
                           │             │            │
                 ┌─────────▼─────┐ ┌─────▼────────┐ ┌─▼──────────────┐
                 │  Read 读取模块 │ │ Write 写入模块│ │ Reflection 反思 │
                 │  （检索经验）   │ │ （筛选重要信息）│ │ （抽象整理/建图）│
                 └─────────┬─────┘ └─────┬────────┘ └─┬──────────────┘
                           │             │            │
                           ▼             ▼            ▼
        Observation ──► [ 相关经验 + 当前观察 ] ──► LLM 文字接龙 ──► Action
```

### 1. Read 模块（读取）

- **职责**：从长期记忆中选择与"当前要解决的问题"相关的经验，放在 observation 前面，让模型只依据这些相关经验做决策。
- **实现**：本质就是一个 **Retrieval（检索）系统**——当前 observation 是 query，长期记忆是数据库。
- **与 RAG 的关系**：**技术完全就是 RAG**，任何 RAG 方法都能直接套用；唯一区别是记忆库里存的是 **Agent 自己的经历**，而非别人的/全网的知识。见 [[RAG]]。

### 2. Write 模块（写入）

- **职责**：决定哪些信息值得写入长期记忆，避免记忆库被"鸡毛蒜皮的小事"塞爆（AI 村民观察到的多是"那里有张桌子、啥事没有"）。
- **实现**：可以就是 Agent 自己（另一个 LLM 调用），自问"**这件事重要到应该记下来吗？**"重要的才写，不重要的随它去。
- **实例**：ChatGPT 的记忆功能——明确说"把这件事记下来"基本必然触发 Write 模块；它会把对话内容**升华反思后再存**，因此可能存错（如把老师误记为台湾大学学生）。

### 3. Reflection 模块（反思）

- **职责**：对记忆中的信息做 **更高层、更抽象**的重新整理，提炼新想法、建立经验之间的关系。
- **实现**：也是一个 LLM（可以是 Agent 自己）——把过往记忆丢给它，让它从记忆里得出新的推论（如"他今天对我笑了 → 他喜欢我"这类从观察推得的结论），或用记忆构建 **Knowledge Graph**。
- **与 GraphRAG**：构建知识图谱后可直接套用 **GraphRAG**、**HippoRAG**（海马回类比）等基于图检索的 RAG 手法，提升 Read 模块的检索质量。

## 实验证据：StreamBench

**StreamBench** 是衡量 Agent"从经验中学习"能力的 Benchmark：Agent 依序解决一系列有标准答案的问题，每答完一题获得对/错反馈，用过往经验修正后续回答，最终以全程平均正确率衡量。

| 策略 | 平均正确率（示意） |
|------|------------------|
| 不学习，每题独立回答（灰线） | 最低 |
| 固定随机选 5 个例子（黄线） | 中等 |
| **RAG 式从 Memory 检索相关经验（粉线）** | 明显更高 |
| 论文最优方法（红线） | 最高 |

**关键发现：负面反馈基本无帮助。**
- 只提供负面例子：基本无帮助，甚至有害。
- 只提供正面例子：所有数据集上均更好。
- 普遍规律："告诉模型**要做什么**"优于"告诉它**不要做什么**"（与其说"不要写太长"，不如直接说"写短一点"）。

## 记忆研究脉络（2023–2025）

- 该方向研究持续产出：**MemoryGPT**（2023）→ **Agent Workflow Memory**（2024）→ **Agent Memory Agent**（2025）。每年一篇代表，说明"Agent 记忆"是从经验调整行为这一方向的核心研究主题。
