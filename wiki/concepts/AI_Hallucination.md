## 定义

**AI 幻觉（Hallucination）** 指语言模型输出**看似合理、实则虚构**的内容（如编造不存在的网址、混淆事实）。李宏毅课程给出的根源性解释：语言模型背后**没有数据库**，一切输出都是"文字接龙"逐 Token 概率采样"梦"出来的——每个字都在幻觉中产生，真正该意外的是幻觉中居然有一部分与现实相符。

## 关键信息

### 典型例子

- 问"台湾大專院校人工智慧學程聯盟 本学期课程 + 官网网址"，模型给出像模像样的介绍和一个**根本不存在的网址** `AI-college.org`。
- 若不了解原理，会误以为是背后数据库有问题；实际上模型没有任何可查的数据库，只是顺着 Prompt 编了一段最"合理"的接龙。

### 为什么会幻觉

1. 语言模型是"关在暗无天日小房间里的接龙者"，看不到外部世界。
2. 生成每一步按概率采样，**低概率但荒谬的 Token 也有机会被选中**，一旦选中后续接龙全盘走偏（课程中"你是谁"接出乱码日文、XD 的演示）。
3. 世界知识无穷无尽、无法全部学会（水的沸点在 0.5 大气压下不是 100℃ 这类条件知识）。

### 减少幻觉的手段

| 手段 | 原理 | 课程出处 |
|------|------|---------|
| **搭配搜索引擎 / [[RAG]]** | 检索到的外部信息作为接龙上下文，抑制凭空编造 | 第二讲展开；作业二做一个 RAG 系统 |
| **确保 Prompt 信息足够（[[Context_Engineering]]）** | 人类负责把必要信息放进输入，模型才有机会接出正确结果 | 第一讲："今天是几月几号"靠 System Prompt 注入日期 |
| **System Prompt 注入基础事实** | 日期、模型身份等每次都塞在对话最前面 | 第一讲实操 |

> 注意：主流平台**默认开启联网/RAG**，复现幻觉通常需先关闭搜索功能；但有搜索也不保证答案正确（工具/搜索结果本身可能不可靠）。
