# 神经网络与深度学习 Neural Network / Deep Learning

## 定义

神经网络（Neural Network）是一种非常有效的技术，用于学习 A→B（输入→输出）的映射。它是大型的数学规则，根据输入 A 计算出输出 B。"神经网络"与"深度学习"这两个词**几乎同义**——几十年前这种软件叫神经网络，如今深度学习是更好的说法。

> ⚠️ **与大脑的关系**：神经网络最初受大脑启发，但其工作的细节**几乎与生物大脑完全无关**。应避免在人工神经网络与生物大脑之间做任何类比。

## 关键信息

### 结构直觉

- 输入 A（如房价预测中的房屋尺寸/卧室数/是否新装修）→ 经过中间层（隐藏层）→ 输出 B（房价）
- 中间结构称为人工神经网络；小圆圈为神经元（节点），通过类似电信号的方式传递信息
- 大型神经网络 = 大型数学规则；训练即在大量数据上调整这些规则

### 课程直觉：需求预测与人脸识别（p8-p9）

- **"乐高积木"类比**：每个神经元（人工神经元）计算一个相对简单的函数；将许多神经元像乐高积木一样堆叠成大网络，就能计算极其复杂的函数——这是神经网络的本质
- **自动学习中间层**：训练时只需提供大量输入 A 与期望输出 B，软件自动确定中间各神经元计算什么，无需人为设计特征
- **需求预测示例**：输入 T 恤价格/运费/营销/材料四个数字 → 神经网络（价格承受能力/知名度/感知质量三个中间神经元 → 需求）→ 输出预估需求
- **人脸识别示例**：计算机看到的是一张像素亮度值网格；灰度图每像素 1 个数、彩图每像素 RGB 3 个数（1000×1000 彩图 = 300 万输入数字）；网络早期层学检测边缘 → 稍后学眼睛/鼻子/嘴 → 后期学面部形状 → 输出身份

### 扩展规律（Scaling）

这是神经网络区别于传统算法的关键特性：

| 模型规模 | 性能随数据量变化 |
|---------|-----------------|
| 传统 AI 算法 | 提升到某点后进入平台期 |
| 小型神经网络 | 更长时间持续改善 |
| 大型神经网络 | **性能持续提升** |

- 要达到最佳性能需要两样东西：**①大量数据** ②**大规模神经网络 + 快速算力**（摩尔定律、GPU 等专用处理器）
- 正是"数据量 × 模型规模"的扩展，驱动了近期生成式AI（LLM）的突破

### 在 AI 家族中的位置

- **AI ⊃ 机器学习 ⊃ 神经网络/深度学习**——深度学习是目前机器学习中最重要的部分，但并非唯一
- 与 [[Supervised_Learning]] 的关系：神经网络是学习 A→B 映射的最有效技术
- 深度学习还有图像识别、语音识别等广义能力
